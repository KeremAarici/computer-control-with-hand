# computer-control-with-hand

------
This Project Made For Windows. Maybe it will work in other operateing systems but I didn't try.
------

Purpose of This Project:
I made this project even though it doesn't work properly because I belive the idea of
the future going to come with some changes. And I belive this idea is the change which future 
will bring to us first. But this is the most prototype version of the idea. I belive that the control of the computers and devices could be controlled with only eye movements in the future and in this path
this project is the starting point of that purpose.

------ 
Requirements:
This Project Made In Python 3.11
so if you have Python 3 or latest versions it will be fine.

OpenCV library
mediapipe library
pyautogui library

Fast install
pip install opencv-python pyautogiu mediapipe

The Steps Of Running This Project
1- Install the libraries. (If you have certain amount of disk capacity I recomend you to use a virtual enviroment)
2- after you install run the project from cmd or your own compiler.
